Gold & Bitcoin Trading Analyzer — V4.6
V4.6 keeps the V4.5 mobile UI concept and changes the signal engine only.
Order of analysis
D1 = primary trend / macro direction
H4 + H1 = market structure and range location
M15 = setup / pullback / breakout / sweep / continuation
M5 = entry trigger
Two horizons shown together
Short Hold: follows H1/M15 tactical direction. It can be counter-macro and is labeled accordingly. Entry requires an M15 setup plus M5 trigger.
Long Hold: follows D1/H4 macro direction. H1/M15 counter-moves are treated as pullbacks/rebounds. Entry requires M15 setup in the macro direction plus M5 trigger.
The setup/trigger scanner checks the latest 3 closed candles so a valid event is less likely to be missed between refreshes.
Entry/SL/TP are shown only for ENTRY READY. PRE-ENTRY and WAIT do not display executable levels.
M5 is candle/relative-volume confirmation only; it is not true bid/ask delta, footprint, DOM, or centralized futures order-flow data.
Data source: Twelve Data REST. The app does not place orders automatically.
